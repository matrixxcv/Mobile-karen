# موبایل کارن — Mobile Karen

وب‌سایت فروش آیفون و خدمات تعمیرات تخصصی موبایل در ملایر، به‌همراه بخش مستقل VPN.

React + TypeScript + Tailwind CSS + Vite + React Router. رابط کاربری کاملاً فارسی و RTL.

## اجرای پروژه

این پروژه در محیطی بدون دسترسی به اینترنت ساخته شده، بنابراین `npm install` هنوز اجرا نشده است. برای اجرا روی سیستم خودتان:

```bash
npm install
npm run dev       # اجرای محیط توسعه
npm run build     # ساخت نسخه نهایی برای production
npm run preview   # پیش‌نمایش نسخه build شده
```

نیازمندی: Node.js نسخه ۱۸ به بالا.

## ساختار پروژه

```
src/
  components/        کامپوننت‌های مشترک (Header, Footer, ProductCard, ...)
  components/vpn/     زیرکامپوننت‌های بخش VPN
  data/                داده‌های محصولات (۱۵ مدل آیفون)، تعمیرات، VPN
  pages/               صفحات اصلی سایت (هر مسیر = یک صفحه)
  pages/vpn/           صفحه اصلی بخش VPN
  types/               تایپ‌های TypeScript
```

## نکات مهم

- **قیمت‌ها**: در تمام سایت به‌صورت «برای استعلام قیمت تماس بگیرید» نمایش داده می‌شوند. هیچ قیمتی جعل نشده است.
- **تصاویر محصولات**: مسیر هر تصویر در `public/assets/products/<model-id>/1.jpg` تا `4.jpg` تعریف شده است (پوشه‌ها موجودند اما فایل تصویر واقعی داخلشان نیست). تا وقتی عکس واقعی جایگزین نشود، در کارت‌ها و صفحه جزئیات به‌صورت خودکار یک آیکون گوشی نمایش داده می‌شود (fallback). برای افزودن تصویر واقعی، فقط فایل‌های jpg را در پوشه مدل موردنظر کپی کنید — نیازی به تغییر کد نیست.
- **بخش VPN**: تمام داده‌های سرور، سرعت، پینگ و مقایسه سرویس‌ها به‌صراحت «نمونه» و placeholder هستند (فایل `src/data/vpn.ts`) و به هیچ API واقعی متصل نیستند. ساختار به‌گونه‌ای طراحی شده که بعداً بدون بازنویسی کل سایت بتوان API واقعی وصل کرد.
- **نقشه فروشگاه**: کامپوننت `src/components/LocationMap.tsx` یک جایگاه بصری آماده اتصال به Google Maps یا نقشه‌های ایرانی است — در حال حاضر نقشه زنده بارگذاری نمی‌شود.
- **ساعات کاری فروشگاه**: چون اطلاعات دقیق در اختیار نبود، در `src/data/repairs.ts` (`STORE_HOURS`) به‌صورت فیلد قابل‌ویرایش قرار داده شده و جعل نشده است.
- **مشخصات فنی آیفون‌ها**: برای سری‌های ۱۳ تا ۱۶ بر اساس اطلاعات عمومی شناخته‌شده هر مدل نوشته شده. برای سری ۱۷ (جدیدتر) عبارت «تقریبی» و توضیح «قابل ویرایش است» به مشخصات وزن اضافه شده تا مشخص باشد نیاز به تأیید نهایی دارد. تمام این مقادیر در `src/data/products.ts` به‌راحتی قابل ویرایش‌اند.

## راه‌اندازی سریع

### Lovable
فایل ZIP را در پروژه/محیط Lovable وارد کنید و از Lovable بخواهید پروژه را اجرا و build کند.
این پروژه با Vite + React + TypeScript ساخته شده و alias `@/*` به `src/*` تنظیم شده است.

### اجرای محلی
```bash
npm install
npm run dev
```

برای build نهایی:
```bash
npm run build
npm run preview
```

> اگر `npm install` روی شبکه شما timeout می‌شود، مشکل از دریافت پکیج‌ها از npm registry است، نه لزوماً از کد پروژه.
