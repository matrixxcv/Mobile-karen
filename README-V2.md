# موبایل کارن — نسخه ۲

این نسخه روی پروژه موجود موبایل کارن ساخته شده و شامل مسیر آماده برای Supabase، احراز هویت، دیتابیس، RLS، پنل ادمین، سفارش و اتصال امن درگاه است.

## 1) نصب
npm install
npm run build

## 2) Supabase
1. یک پروژه Supabase بسازید.
2. SQL داخل `supabase/migrations/0001_mobile_karen.sql` را در SQL Editor اجرا کنید.
3. `.env.example` را به `.env` تبدیل کنید و `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` را قرار دهید.
4. برای ادمین، بعد از ساخت حساب، نقش کاربر را در جدول `profiles` به `admin` تغییر دهید.

## 3) درگاه پرداخت
درگاه واقعی باید با اطلاعات پذیرنده فروشگاه متصل شود. تابع `supabase/functions/create-payment/index.ts` عمداً کلیدها را سمت سرور نگه می‌دارد. سه Secret زیر را در Edge Function تنظیم کنید:
- PAYMENT_GATEWAY_URL
- PAYMENT_MERCHANT_ID
- PAYMENT_CALLBACK_URL

بدون Merchant ID/کلید و قرارداد درگاه، هیچ کدی نباید ادعا کند پرداخت واقعی فعال است.

## 4) تغییرات این نسخه
- آدرس فروشگاه: ملایر، چهارراه چمران، نبش پاساژ میلاد نور
- دسته لوازم جانبی: شارژر، کابل، هندزفری، تبدیل، قاب
- VPN فقط SSH و NPV
- ورود و ثبت‌نام Supabase
- پروفایل و نقش admin
- محصولات، سفارش‌ها، آیتم سفارش، تعمیرات و سرویس VPN در دیتابیس
- RLS برای جداسازی اطلاعات کاربران
- پنل مدیریت اولیه
- تابع امن شروع پرداخت
